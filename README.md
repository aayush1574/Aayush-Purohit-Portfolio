# Aayush Purohit Portfolio

Personal portfolio showcasing AI agents, voice AI, automation, cloud engineering, and Java projects.

## Local preview

```powershell
python -m http.server 4173 --directory dist
```

Open `http://localhost:4173`.

The deployable static site is in `dist/`. The main page is `dist/index.html`, with shared styles and behavior in `dist/assets/`.

The visual direction is adapted from the user-selected reference at https://www.aahil-khan.xyz/. Portfolio content comes from Aayush Purohit's supplied résumés and public project repositories.
